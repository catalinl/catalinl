## 🤖 My Agentic Workflow

My goal isn't to make AI write code faster.

It's to make the **whole development process faster**.

A typical workflow looks something like:

```text
Understand the problem
        ↓
Explore the codebase
        ↓
Define the desired outcome
        ↓
Ask the agent to investigate
        ↓
Challenge / refine the approach
        ↓
Implement
        ↓
Run tests & validate
        ↓
Review the result
        ↓
Iterate
```

I increasingly treat AI agents as **development collaborators** rather than autocomplete tools.

The developer's role shifts from writing every line of code to:

* understanding the problem
* providing context
* defining constraints
* making architectural decisions
* validating the implementation
* reviewing the result
* keeping complexity under control

**The important skill is no longer just "how fast can I write code?" — it's "how effectively can I direct and validate the system?"**

## 🎯 What I care about

### Keep it simple

I strongly believe that good software doesn't need to be complicated.

I prefer:

* simple architecture over clever architecture
* readable code over abstractions for the sake of abstractions
* solving the actual problem over following patterns blindly
* boring solutions that work over impressive solutions that don't

### User experience

I'm particularly interested in the intersection of **engineering and UX**.

A technically perfect application is not necessarily a good application.

I care about:

* intuitive interactions
* responsiveness
* performance
* accessibility
* visual clarity
* reducing friction for the user
